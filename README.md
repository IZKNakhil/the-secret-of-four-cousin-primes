# The Secret of Four — The Geometry of Cousin Primes

**A mathematical visualization of prime numbers and cousin-prime pairs, rendered as a vertical 60-second animation.**

This project explores the geometry created when prime numbers are mapped to the plane using a simple deterministic rule. First, all primes in a chosen range are plotted. Then, the visualization retains only primes belonging to **cousin-prime pairs**, whose members differ by exactly four. Finally, the remaining points are colored according to their residue classes modulo six.

The resulting spiral-like structures consist of **individual points only**. No curves, connecting lines, or manually positioned points are used.

## Mathematical definition

Each prime number `n` is mapped to a point using

$$
x(n) = n\cos(n), \qquad y(n) = n\sin(n),
$$

where trigonometric arguments are measured in **radians**. Equivalently, the polar coordinates are `r = n` and `theta = n`.

A **cousin-prime pair** is `(p, p + 4)` where both integers are prime. For example, `(3, 7)`, `(7, 11)`, and `(13, 17)`.

Every prime greater than three satisfies

$$
p \equiv 1 \pmod{6} \quad\text{or}\quad p \equiv 5 \pmod{6}.
$$

The visualization colors cousin primes congruent to `1 mod 6` **cyan**, those congruent to `5 mod 6` **gold**, and the exceptional prime `3` **white**. The prime `2` does not belong to any cousin-prime pair.

These are established mathematical facts. The visual patterns arise from the selected coordinate mapping and the prime-number sequence; the project does not claim a new theorem about primes.

## Counts for the default range

For integers up to **1,000,000**, inclusive:

| Quantity | Count |
|---|---:|
| Prime numbers | 78,498 |
| Cousin-prime pairs `(p, p + 4)` | 8,144 |
| Distinct prime numbers belonging to these pairs | 16,287 |

A prime number may belong to two cousin-prime pairs but is plotted only once in the cousin-prime visualization.

## Video timeline

| Time | Visual |
|---|---|
| 0–3 s | Opening view of the complete prime spiral |
| 3–4 s | Fade and reset |
| 4–22 s | Progressive reveal of all prime numbers |
| 22–32 s | Non-cousin primes fade out |
| 32–49 s | Cousin primes are colored by residue class modulo 6 |
| 49–60 s | Final reveal with a clear, high-contrast footer |

The Python animation renders a **silent 60-second, 1080 × 1920, 30 FPS MP4**. The published **63-second documentary version** was made in post-production by adding a separate English voiceover and extending the final frame by three seconds. The narration is **not generated by this Python script**.

## Usage

**Preview (no video render):**

```bash
python the_secret_of_four.py
```

The default is a PNG preview at 55 seconds. To preview a different point in the animation:

```bash
python the_secret_of_four.py --preview-second 28
```

**Render the 60-second Full-HD video:**

```bash
python the_secret_of_four.py --render
```

**Change the number range:**

```bash
python the_secret_of_four.py --max-n 10000000 --preview-second 55
```

You can also change `MAX_N`, `PREVIEW_ONLY`, `FPS`, `DURATION`, and styling options near the top of `the_secret_of_four.py`. The current implementation uses an in-memory prime sieve and limits `MAX_N` to 50,000,000.
